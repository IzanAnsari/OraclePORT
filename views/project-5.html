Project Overview

Built and managed integration flows in Oracle Integration Cloud (OIC) to automate business processes between Oracle Fusion Cloud modules and external applications. Used prebuilt connectors such as ERP Adapter, REST Adapter, and FTP Adapter for seamless connectivity.

Implemented orchestration integrations to transform and route data across systems, handling complex data mappings, XSLT transformations, and business rules. Configured trigger-based integrations and scheduled flows to manage real-time and batch processing.

Ensured secure communication using OAuth 2.0 and basic authentication. Monitored and troubleshooted integrations through OIC dashboard and logs, improving system efficiency and data accuracy across all endpoints.
